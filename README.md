# 古文リーダー

古文の名文を**縦書き**で読み、語をクリックすると**品詞・活用の種類と活用形・意味・語法メモ**が引ける学習サイト。

公開先： GitHub Pages（`deploy.command` をダブルクリックすると公開されます）

## 使い方

- 語をクリック／タップ → 左（スマホは下）のパネルに語釈が出ます。矢印キーで前後の語へ。
- **助動詞一覧**タブ → その章段の助動詞を出現順に並べ、クリックで本文へジャンプ。
- **品詞を強調** → 助動詞・動詞・形容詞などに帯を掛けて拾い読み。
- **敬語に圏点** → 敬語にゴマ点が付き、パネルに尊敬／謙譲／丁寧の別が出ます。
- **現代語訳** → 各段の左に訳の列が立ちます。
- **読み仮名** → 読みのある語にルビを振ります（漢文は既定でオン）。
- **要チェック** → 句法・助動詞・敬語・難読語・語法メモのある語に帯を掛けます。
- **頻出** → テストでねらわれやすい箇所に枠が付きます。語釈パネルの「頻出」タブで問いと答えを確認できます。
- **辞書・活用表** → 語をひらくと、語釈の下に単語帳の語義（その語が持つ他の意味も）と、文法書の形の活用表（現在の活用形の欄に色がつく）が出ます。練習のカード裏にも同じものが出ます。
- **拡大縮小** → 二本指ピンチ、Ctrl＋ホイール、⌘＋ / ⌘− / ⌘0。拡大中は一本指で紙を動かせます。
- **PDF** → 縦書きのまま高画質（ベクタ）で書き出せます。
- **★** → 章段をお気に入りに入れると、作品一覧の先頭に並びます。

## PDF に書き出す

本文ページの **PDF** ボタン（`assets/pdf.js`）。画面を画像に写し取るのではなく、印刷用の紙面を組み直します。

- **字はベクタのまま**入るので、拡大してもぼけず、PDF の中を検索・選択できます
- 縦書きのまま、紙の大きさに合わせて自動でページを分けます（測ってから組み直す二段構え）
- 用紙 A4／B5 の縦横、字の大きさ3段階、余白3段階、**字間**3段階、**行間**3段階
- **背景色** 白／生成り／セピア／薄グレー／濃紺（濃紺は文字が白抜きになります）
- **段ごとに行を改める**（既定でオン）。白文・現代語訳もそれぞれ行頭から始まります
- 入れるものを選べます：現代語訳・読み仮名・敬語の圏点・品詞の色分け・句法や語法メモの印・白文（漢文）
- 開いたときの設定は画面の表示状態を引き継ぎます

書き出しはブラウザの印刷ダイアログ経由です。保存先で「PDFとして保存」を選んでください（iPad は共有 → プリント → ファイルに保存）。

## 辞書と活用表

- `assets/lexicon.js` … 見出し語ごとの語義。用言は基本形、それ以外は本文の表記がキー。表記のゆれは `LEXALIAS` で寄せる。
- `assets/conj.js` … 活用表。助動詞は表を直に持ち、用言は活用の種類と基本形から自動で組み立てる。
- **練習** → 章段ごとに4つのモード。
  - テスト対策（頻出ポイントの一問一答。全14章段で98問。`assets/spots.js` に手書き）
  - フラッシュカード（表に語と文脈、裏に品詞・活用・意味。「覚えた」で仕分け）
  - 単語クイズ（語→意味／意味→語／読み の四択10問。終わりに間違えた語の一覧）
  - 文法問題（句法／品詞／活用の種類と活用形／助動詞の説明／敬語の種類 の四択10問）
  - 出題の範囲を「すべての語／要チェックのみ」で切り替えられます

## 漢文の章段について

漢文（`genre:'漢文'`）は表示が変わります。

- **白文を書き下し文の右に置き、既定で表示**（読む順に並ぶ）
- **読み仮名を既定でオン**
- 語釈パネルに**句法タブ**が加わり、句法ごとにまとめて一覧・ジャンプできる（本文では金色の下線）
- 練習の文法問題に**句法の問題が毎回4問**入る

句法は本文データの語に `ku:'反語'` のように印を付けると拾われます。

お気に入りと学習の記録は、その端末のブラウザ（localStorage）にだけ保存されます。

## 章段を足すには

1. `texts/` に `<id>.js` を 1 つ置く（既存ファイルをまねる。`W()` が一語、`P()` が記号、`BR()` が改行）
2. `build.py` の `ORDER` に id を加える（省略すると末尾に並びます）
3. `python3 build.py` を実行 → ページと作品一覧が自動生成されます

## 構成

```
index.html            作品一覧（build.py が生成）
<id>.html             各章段のページ（build.py が生成）
assets/style.css      全ページ共通のスタイル
assets/kit.js         データ記述用のヘルパー W / P / K / BR
assets/reader.js      本文の組み立てと語釈パネル
assets/works.js       収録一覧（build.py が生成）
texts/<id>.js         本文＋品詞分解データ（手で書くのはここだけ）
build.py              ページ生成
deploy.command        GitHub Pages への公開
```

本文は著作権の切れた古典作品。品詞分解・現代語訳・語法メモは学校文法（古典文法）に沿って書き起こしたものです。
