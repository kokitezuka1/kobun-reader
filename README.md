# 古文リーダー

古文の名文を**縦書き**で読み、語をクリックすると**品詞・活用の種類と活用形・意味・語法メモ**が引ける学習サイト。

公開先： GitHub Pages（`deploy.command` をダブルクリックすると公開されます）

## 使い方

- 語をクリック／タップ → 左（スマホは下）のパネルに語釈が出ます。矢印キーで前後の語へ。
- **助動詞一覧**タブ → その章段の助動詞を出現順に並べ、クリックで本文へジャンプ。
- **品詞を強調** → 助動詞・動詞・形容詞などに帯を掛けて拾い読み。
- **敬語に圏点** → 敬語にゴマ点が付き、パネルに尊敬／謙譲／丁寧の別が出ます。
- **現代語訳** → 各段の左に訳の列が立ちます。漢文の章段では**白文**の列も出せます。
- **★** → 章段をお気に入りに入れると、作品一覧の先頭に並びます。
- **練習** → 章段ごとにフラッシュカードと確認問題（各10問）。品詞分解データから自動生成されます。

お気に入りと学習の記録は、その端末のブラウザ（localStorage）にだけ保存されます。

## 章段を足すには

1. `texts/` に `<id>.js` を 1 つ置く（既存ファイルをまねる。`W()` が一語、`P()` が記号、`BR()` が改行）
2. `build.py` の `ORDER` に id を加える（省略すると末尾に並びます）
3. `python3 build.py` を実行 → ページと作品一覧が自動生成されます

## 構成

```
index.html            作品一覧（build.py が生成）
<id>.html             各章段のページ（build.py が生成）
assets/style.css      全ページ共通のスタイル
assets/kit.js         データ記述用のヘルパー W / P / K / BR
assets/reader.js      本文の組み立てと語釈パネル
assets/works.js       収録一覧（build.py が生成）
texts/<id>.js         本文＋品詞分解データ（手で書くのはここだけ）
build.py              ページ生成
deploy.command        GitHub Pages への公開
```

本文は著作権の切れた古典作品。品詞分解・現代語訳・語法メモは学校文法（古典文法）に沿って書き起こしたものです。
